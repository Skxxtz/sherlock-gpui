#
#   SLOT  = a | b c | …     values used for training
#   SLOT? = a | …           dev values (held out; tune against these)
#   SLOT! = a | …           test values (held out; final number only)
#   #                       a random number (1–90), e.g. `#m` → `25m`
#
# Real slot values (installed apps, …) come from the system at runtime;
# these only need to teach the model what such values look like.
