# Training templates for parley.
#
# Syntax
#   @name = a | b c | d      word list; choices may be several words or empty
#   intent: words …          a template (intent = timer, remind, open, search,
#                            volume, or none for things that are NOT commands)
#   {DUR} {TIME} …           a slot, filled from data/slots.txt
#   @name                    one choice from a list
#   [x]                      optional: x or nothing (x = word, @list or {SLOT})
#
# Three sections:
#   (top)        training data
#   == dev ==    held out from training; look at its errors, tune against it
#   == test ==   held out from everything; only for the final number.
#                Don't look at its errors and don't tune against it, or it
#                stops measuring anything.
# Keep held-out phrasings genuinely different; the leak tests check this.

@please  = please | for me | quickly
@can     = can you | could you | pls
@new     = new | set | start | make | create | begin
@then    = then | and | and then
